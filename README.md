## O que faço no dia a dia

- SQL Server (T‑SQL): views, stored procedures e consultas performáticas para rotinas de DP (admissão/demissão, férias, folha). Uso CTE, índices e plano de execução para otimização.
- Power BI: modelagem em Power Query e DAX, integração de múltiplas fontes e criação de dashboards executivos com KPIs e atualização agendada.
- Power Apps / Power Automate: aplicativos e fluxos para padronizar solicitações, eliminar digitação manual e garantir rastreabilidade.
- Python: ETL e automação de manipulação de planilhas/arquivos para alimentar bases e relatórios.
- .NET (C#): apoio em APIs internas e integrações simples com SQL Server (CRUD), acelerando a disponibilização de dados.
